# Space Apps project handoff

This repository is the public code and distribution companion for **AISTRO / Flame in Freefall**, an independent student project for the 2026 NASA Space Apps Challenge. Publishing the repository does not submit the project or establish judging eligibility.

| Resource | Public address |
|---|---|
| Team and project page | https://www.spaceappschallenge.org/2026/find-a-team/aistro/?tab=project |
| Final project source and documentation | https://github.com/ahmet123taha/aistro-flame-in-freefall |
| Live application | https://aistro-flame-freefall.duckdns.org |
| Windows portable and release assets | https://github.com/ahmet123taha/aistro-flame-in-freefall/releases/tag/v0.5.2 |
| Dataset description and installation | [data/README.md](../data/README.md) |

The repository, release downloads, and live application are intended to be accessible without sign-in. The team should check the final links from a signed-out browser before submitting. Local AI use requires the reviewer's own provider key; the hosted demo keeps its operator key server-side.

## What this repository supplies

- The versioned application source and Windows portable archive.
- A concise overview, source-backed architecture, installation instructions, and artifact hashes.
- An Apache-2.0 license for original code/documentation, with external rights kept separate.
- Third-party software notices, data provenance and distribution documentation, and an AI-use disclosure.
- Clear limitations distinguishing research support from approved scientific or safety conclusions.

The project submission should explain how the NASA PSI resources were actually used, identify the relevant challenge, and cite all other tools, datasets, text, and visual assets. NASA sources and other resources belong in the corresponding fields of the project form. The repository complements those fields; it does not automatically populate them.

## Demo and final submission

The team's requested **public 30-second demonstration video** is a separate deliverable. **No final video URL has been verified for this repository.** Do not substitute a private file link or an invented address. Add the completed public demo to the project form and README once it has been checked without login.

The [official 2026 page](https://www.spaceappschallenge.org/2026/) states that projects are edited and submitted through the team's Project tab, with submission closing on November 15 at 23:59 local time. Confirm the team's applicable event/time zone and the live form's required fields. Actual submission, team declarations, and eligibility remain the team's responsibility.
