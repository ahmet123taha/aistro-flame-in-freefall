# Dataset licenses and redistribution scope

The application license does not relicense scientific data or third-party publications. This release retains original source notices and distinguishes bundled files from source links.

| Material | Basis and treatment |
|---|---|
| NASA PSI experiments | 23 of the 24 pinned investigation metadata records identify **CC0-1.0**, and all 24 indicate unrestricted access. PSI-10 (ACME/Flame Design) has a blank license field; NASA’s default policy for NASA-led mission data is recorded separately rather than inventing a metadata license. Preserve original notices and cite the investigation DOI. |
| NASA supporting documents | Official NASA/government source links and original notices are retained. Separately credited third-party material keeps its own terms. |
| MaCFP `matl-db` and `macfp-db` | Original files included with their MIT LICENSE files and laboratory/source citations. |
| UL FSRI Materials and Products Database | No repository LICENSE was located in the pinned source tree. Originals are not republished here. The release includes source references and limited locally authored factual/analytical material-applicability metadata. |
| Manufacturer, instrument and other laboratory references | DuPont, Dow, NETZSCH, Thermtest, UConn and other unresolved source terms are not replaced by this project’s license. Their original files are linked rather than bundled. |
| NIST reference compilations and SHCDB | Source-specific database/data notices apply. These originals are linked rather than assigned a blanket public-domain status. |
| Extracted research text and prepared graphs | Derived from the identified core sources; they retain the underlying source terms and attribution. Extraction is not scientific validation. |

The authoritative per-file provenance is retained in the dataset’s manifests and the [third-party source list](third-party-sources.json). The [publication policy](publication-policy.json) states the directory allowlist and exclusions used for this release.

The optional source-restoration script is an explicit retrieval tool for people entitled to use those sources. Its acknowledgement flag is not a license grant, and restoring a file does not give permission to republish it. It downloads only pinned, publicly reachable HTTPS originals and verifies their exact bytes.

References: [NASA Science Data Licenses](https://science.data.nasa.gov/about/license), [NASA media-use guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/), [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/), [MaCFP matl-db](https://github.com/MaCFP/matl-db), [MaCFP macfp-db](https://github.com/MaCFP/macfp-db).
