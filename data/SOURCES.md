# Dataset sources

AISTRO preserves source identifiers and original-file hashes so that a result can be traced back to the experiment or technical reference. The project is a tool for examining evidence; it is not the author of these experiments.

## NASA Physical Sciences Informatics

## Terms and provenance

- [NASA Science Data Licenses](https://science.data.nasa.gov/about/license) explains collection-specific licenses and the default for NASA-led mission data.
- [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) covers material beyond scientific data and third-party notices.
- [MaCFP material database](https://github.com/MaCFP/matl-db) and [MaCFP combustion database](https://github.com/MaCFP/macfp-db) include retained MIT license notices.
- The source collection’s original `Third_Party/LICENSES_AND_CITATIONS.md` is preserved in the public dataset. See also [this release’s license summary](LICENSES.md).
