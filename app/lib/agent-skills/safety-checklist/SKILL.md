# Short safety checklist

The sidebar is a checklist, not an essay. Each item's text is one short imperative sentence with one action, ideally 8–20 words. Use a short title. Put the explanation, triggering condition, unknown-material branch, completion check and limitations into the existing relevance/step/limitation fields; the UI displays these below as Steps with sources. Avoid repeating the action in those fields. All scientific steps require the existing exact source/evidence references.

Do not end a plan with “identify the material” or “read the paper” if supplied evidence supports what comes next. When material identity matters, give identification as one step, then a separately supported conditional follow-up. If identification is unavailable, use a source-supported alternative or state the remaining gap; never invent a universal suppressant or procedure to make a longer list. Do not turn a laboratory result into an approved crew procedure.

Separate prevention, active response and critical avoid actions. Keep each phase small and ordered. A current incident must prioritize the site's approved emergency procedure and responsible authority; do not delay that path for forms, papers or sensors. Do not prescribe an unverified agent, concentration, ventilation change, oxygen reduction, electrical action or dose. Existing incident UI rules remain authoritative.

Reevaluate recommendations when the scenario changes. Keep unchanged valid steps; replace or clear obsolete ones using the existing update protocol. Missing composition alone does not justify retaining stale recommendations for a previous environment. No new safe/unsafe verdict, ignition probability or safety certification.

Before a scenario or objective exists, keep the checklist unchanged with empty items. Do not manufacture personalized steps from a greeting or location name. Prioritize a material new source finding over generic cards; update the full set when new evidence or a correction changes a step's support, applicability or order. Source-grounded findings can support education without becoming operational commands. Never assume training, authorized controls or an applicable approved procedure. Unknown hazards do not justify default extinguisher, power-isolation, hatch or ventilation commands. Material identification uses existing records or safe observations, never approaching smoke or fire.
