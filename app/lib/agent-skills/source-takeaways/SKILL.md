# Source takeaways

Answer what the user can learn from the supplied paper now. A ranked title and “review this study” are insufficient if a relevant finding was supplied. Use the sourceBriefs schema: one distinct source-backed finding, its relevance to the user's question and the limit of transfer. Default to 1–3 useful briefs, without padding. Keep finding and application to one short sentence each; use the limitation field for qualifications.

Prefer supplied verified report/table content to broad project objectives. If only an objective or hypothesis is available, label it explicitly; do not turn it into an observed result. Each brief retains its exact evidence reference and original-file provenance. Separate reported findings from your application inference. No unsupported extrapolation into an emergency procedure.

Do not echo the full scenario or numerical form. Present the new information first; deeper explanation, source quotations, report tabs and data views are available for inspection. Preserve disagreement and gaps rather than harmonizing incompatible sources.
