## Implemented design

FIF-054 extends authenticated literal discovery to PDF/log shards and bounded CSV/TXT/XLSX/DOCX/PPTX parts. Source text keeps explicit sheet, logical CSV record, physical line and partial-record/prefix scope. Files are ranked before parts. Question/phrase relevance precedes material tie-breaking; one explicit material passage/file is reserved when existing budgets allow. Phrase/proximity and diversity features affect retrieval only. Literal quotations remain unchanged, raw text never becomes normalized measurements automatically, shared catalog associations are not experiment assignments, and Material_Sensitivity remains applicability-only. Pure-number lookup limits and skipped/partial source states stay visible.

The runtime defaults to at most 48 selected parts/shards, ten emitted hits and 10,000 characters including table context. Streamed parts enforce 512 KiB decoded limits; existing document shards retain separate bounds. Paths are confined including Windows cross-drive cases, and every alias actually used for an accession is source-hash checked. The producer's older 8 MiB unit check is post-allocation and is not a strict 8 MiB heap bound. Final mixed manifest counters and version pin are not inferred from running progress.

FIF-055 supplies safe shared local source links for scored/unscored evidence and candidate passages. Positive PDF pages, worksheet/cell/DOCX paragraph/table/XML-part and PPTX slide locations and explicit row/line ranges are retained; CSV logical records are not relabeled as physical lines, and no byte offsets are invented. Direct/cached validation derives genuine file provenance and discards forged properties. Startup keeps legacy inputs hidden until environment installation succeeds; failures show a persistent English notice. Status wording separates recovered, partial, unread and excluded text from scientific review. When material is unspecified, the coverage label says inputs assessed from indexed source values; this wording change does not alter eligibility, points or weights.
